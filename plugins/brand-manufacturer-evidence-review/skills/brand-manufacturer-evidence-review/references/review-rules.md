# 证据复核规则

## 主体与关系

- 分别记录商标权利人、品牌运营主体、母公司、控制主体、品牌层面制造商和具体 SKU 制造商。即使同一法律主体承担多个角色，也不得合并这些关系。
- 每项主体关系标注为当前、历史或不确定。历史权利人、被收购公司或旧目录中的主体，在缺少当前证据时不得表述为当前权利人或当前制造商。
- 品牌层面制造证据与具体 SKU 制造证据相互独立。没有标签、包装、说明书、型号、SKU 或同等产品资料时，具体 SKU 制造商保持为空，并明确其适用限制。

## 证据评估

- 优先使用官方登记、官方企业资料、官方产品文件、监管或法院文件；可靠商业资料可作补充，其他资料应说明局限。
- 可靠性为高：官方登记与官方产品或企业资料相互印证；中：主体关系有合理支持但当前所有权或制造责任仍需补证；低：主要为间接证据或存在未解决冲突。
- 每项关键结论链接全局唯一的 `EVD-xxx` 证据；客户材料使用独立的 `SRC-xxx` 标识。不得将两类来源混用。
- Amazon 页面、经销商页面和搜索摘要不能单独证明商标权利人或制造商。它们可以提供调查线索，但必须取得更直接的支持证据。
- 真实网络检索是调查前置条件：至少记录一次官方登记/监管数据库检索和一次品牌/产品官方页面检索。检索记录必须包含检索词、URL、访问时间、页面是否可访问、提取结果及失败原因。
- 每条 `EVD-xxx` 必须包含可复核的原文摘录或结构化字段、页面定位（页码/章节/字段/截图编号之一）和支持的具体主张；只有来源名称或 URL 不构成证据对象。
- 没有网络检索记录、原文摘录或页面定位时，相关主张不得标记为“已确认”。

## 未知、冲突与确认

- 无法确认的结论明确标为证据不足；名称相似不足以确认法律主体一致性。存在相互矛盾的可靠来源时保留冲突及其原因，不得自行选择一方。
- 在展示品牌、主体角色、制造范围、可靠性、证据与限制的完整摘要后，接收用户修正并重新校验草稿。
- 只有用户对待写入内容作出明确确认，才能写入最终 JSON 并生成 DOCX；沉默不构成确认。未知或冲突未完全消除时，用户仍可确认一份如实披露限制的记录。

## 交付与复用

- 最终 JSON 通过校验后，DOCX 只能从该 JSON 生成；DOCX 不得独立维护事实。
- 后续消费者必须读取已确认 JSON，而不是解析 DOCX；使用主体关系时保留角色、时间状态、可靠性、证据引用和适用限制。
